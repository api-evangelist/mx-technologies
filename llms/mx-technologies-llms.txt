# MX Documentation

> Developer documentation for the MX platform. Covers connecting users to their financial institutions and retrieving enhanced account, transaction, and verification data with the Platform API and Connect Widget; Financial Insights, Personal Finance Management (PFM), and mobile banking experiences; and data products including Data Access, Customer Analytics, and Audiences.

## Connect Widget

### Connect Widget

- [Connect Widget Overview](https://docs.mx.com/connect/index.md): Overview of the Connect Widget for searching and connecting user accounts. Covers retrievable data, browser support, OAuth, session timeouts, and member use cases.
- [Best Practices](https://docs.mx.com/connect/best-practices.md): Make the most of your Connect Widget integration with these practical tips.
- [Connect Widget UI Walkthrough](https://docs.mx.com/connect/ui-walkthrough.md): Explore the Connect Widget UI and common flows including credential, OAuth, verification, microdeposits, MFA, and error handling.
- [MXquickconnect Demo App](https://docs.mx.com/connect/demo-app.md): Set up the MXquickconnect demo app to explore the Connect Widget. Covers cloning, backend setup, frontend setup, and sample Platform API requests.
- [Widget Events](https://docs.mx.com/connect/widget-events.md): Reference for Connect Widget events across Web Widget SDK, React Native SDK, JavaScript Loader, and WebView. Includes troubleshooting and event payloads.
- [Testing the Connect Widget](https://docs.mx.com/connect/testing-the-connect-widget.md): Testing guides for the Connect Widget including member connection statuses, microdeposits, OAuth in WebViews, and MXCU test scenarios.

#### Embed Widget

- [Embed Widget](https://docs.mx.com/connect/guides/index.md): Integration options for embedding the Connect Widget.
- [React Native SDK](https://docs.mx.com/connect/guides/react-native-sdk.md): Embed the Connect Widget into your React Native app using the React Native SDK.
- [WebView](https://docs.mx.com/connect/guides/webviews.md): Embed the Connect Widget in a native app via a WebView. Covers widget URL requests, navigation event handling, and OAuth redirect flows.
- [Web SDK](https://docs.mx.com/connect/guides/web-sdk.md): Embed the Connect Widget into your web application using the Web SDK. Covers installation, backend setup, widget URL retrieval, mounting, and unmounting.

### OAuth

#### OAuth

##### OAuth

- [OAuth](https://docs.mx.com/resources/oauth-guide/index.md): OAuth is a secure authentication method for connecting users to financial institutions without exchanging sensitive credentials.
- [OAuth in the Connect Widget](https://docs.mx.com/resources/oauth-guide/oauth-in-connect-widget.md): Build a flow to connect users to their financial institutions using OAuth in the Connect Widget.

### Webhooks

#### Webhooks

##### Webhooks

- [Webhooks](https://docs.mx.com/resources/webhooks/index.md): MX provides HTTPS POST webhooks that deliver event notifications and JSON payloads to your configured URL.
- [Accounts](https://docs.mx.com/resources/webhooks/accounts.md): Accounts webhooks notify you when an account is created, updated, or deleted in the MX system for any user in the client.
- [Aggregation](https://docs.mx.com/resources/webhooks/aggregation.md): Aggregation webhooks notify you when any new data is available after a successful aggregation, including counts of new and updated transactions.
- [Balance](https://docs.mx.com/resources/webhooks/balance.md): Balance webhooks notify you when new data is available after a successful balance fetch for a member.
- [Budgets](https://docs.mx.com/resources/webhooks/budgets.md): Budget webhooks notify you when a budget is created, updated, or deleted in the MX system for any user in the client.
- [Categories](https://docs.mx.com/resources/webhooks/categories.md): Categories webhooks notify you when a category is created, updated, or deleted in the MX system for any user in the client.
- [Connection Status](https://docs.mx.com/resources/webhooks/connection-status.md): Connection status webhooks notify you whenever a member connection_status field enters into an actionable state for the end user.
- [Goals](https://docs.mx.com/resources/webhooks/goals.md): Goals webhooks notify you when a goal is created, updated, or deleted in the MX system for any user in the client.
- [History](https://docs.mx.com/resources/webhooks/history.md): History webhooks notify you when any new data is available after a successful history fetch, including counts of new and updated transactions.
- [Holdings](https://docs.mx.com/resources/webhooks/holdings.md): Holdings webhooks notify you when a holding is created, updated, or deleted in the MX system for any user in the client.
- [Initial Data Ready](https://docs.mx.com/resources/webhooks/initial-data-ready.md): Initial Data Ready webhooks notify you when some initial data you requested has aggregated and is ready for retrieval for Platform API version 20250224.
- [Insights](https://docs.mx.com/resources/webhooks/insights.md): Insights webhooks notify you when an insight is created, updated, or deleted in the MX system for any user in the client.
- [Job Status](https://docs.mx.com/resources/webhooks/job-status.md): Job Status webhooks notify you when a job hits an actionable state, allowing webhooks to replace read job pings from the Nexus API.
- [Members](https://docs.mx.com/resources/webhooks/member.md): Members webhooks notify you when a member is created, updated, or deleted in the MX system for any user in the client.
- [Microdeposits](https://docs.mx.com/resources/webhooks/microdeposits.md): Microdeposits webhooks notify you when a microdeposit is created or updated in the MX system for any user in the client.
- [Notifications](https://docs.mx.com/resources/webhooks/notifications.md): Notifications webhooks notify you whenever an alertable action occurs on the MX system, including channels, contact info, and related details.
- [Spending Plan](https://docs.mx.com/resources/webhooks/spending-plan.md): Spending Plan webhooks notify you when a spending plan is created, updated, or deleted in the MX system for any user in the client.
- [Statement](https://docs.mx.com/resources/webhooks/statements.md): Statement webhooks notify you when new data is available after a successful statement fetch and include a count of new statements.
- [Tags and Taggings](https://docs.mx.com/resources/webhooks/tags-&-taggings.md): Tags and Taggings webhooks notify you when a tag or tagging is created, updated, or deleted in the MX system for any user in the client.
- [Transactions](https://docs.mx.com/resources/webhooks/transactions.md): Transactions webhooks notify you when a transaction is created, updated, or deleted in the MX system for any user in the client.
- [Users](https://docs.mx.com/resources/webhooks/users.md): User webhooks notify you when a user is created, updated, or deleted in the MX system.
- [Verification](https://docs.mx.com/resources/webhooks/verifications.md): Verification webhooks notify you when a member verification is successful.
